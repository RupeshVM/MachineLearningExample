# MachineLearningExample

## 90s Mario Game

This project now includes a small browser game inspired by 90s side-scrolling Mario platformers.

### How to run

1. Open `index.html` directly in your browser, or serve the folder with a basic static server.
2. Controls:
   - `←` / `→`: move
   - `Space`: jump
3. Collect all coins and avoid enemies to win.

### Files

- `index.html` - game shell and HUD.
- `style.css` - retro-inspired visual style.
- `game.js` - gameplay, physics, enemies, and rendering loop.
